ClipMonster 2.2.3 makes automation much less likely to be stopped by YouTube asking your PC to sign in.

## Fixed
- **Fewer requests to YouTube.** Each video's captions now come from the details already fetched for it, where before the video page was loaded a second time. The most-replayed checks during automation now run one at a time, 20 seconds apart, where before four ran at once on every check. A check that failed is retried an hour later, where before it was retried on every check.
- **A real pause.** When YouTube asks the PC to sign in, ClipMonster now stops asking YouTube for anything for 6 hours, including the most-replayed checks, which carried on before and kept the PC flagged. This covers the Research tab's own checks too, and a sign-in request seen there pauses automation as well.
- **Slowing down afterwards.** After a pause, automation leaves twice as long between downloads for a day, and four times as long if YouTube asks again that day.
- **Clearer status.** The Automation tab says the pause is not an error and that automation carries on by itself.
- **Stopping during a check.** Stop, and updating, no longer wait for a long check of what to clip to finish.
- **Captions.** A caption download that hits a dropped connection is tried again rather than skipped.

## Tip
If YouTube still asks often, set **Settings → Download → Use browser login** to a browser signed in to a spare Google account (not your main one). Firefox works most reliably on Windows.

## Updating
Installed copies offer this update automatically. Close ClipMonster's other windows first; automation pauses for the update and starts again afterwards.
