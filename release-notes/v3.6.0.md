ClipMonster 3.6.0 adds **ClipMonster Remote**, a Mac app that runs ClipMonster on your PC. The PC keeps doing the work: clipping, Creator videos, the local AI and posting. On the Mac you watch what's waiting, OK it or delete it, ask for new videos and keep an eye on automation, over an encrypted connection that only Macs you link can use.

## New
- **ClipMonster Remote for Mac.** Download `ClipMonster-Remote-mac.dmg` (Apple silicon) or `ClipMonster-Remote-mac-intel.dmg` (Intel Mac) below and drag the app to Applications. On the PC, open **Settings → Mac app**, tick **Let my Mac run ClipMonster**, Save, and press **Link a Mac**. Then pick the PC in the Mac app and type the code. From the Mac:
  - **Overview**: what automation is doing right now, with the same step bar as the Automation tab. Also: videos waiting for your OK, the queue, today's posts, free disk space, what's up next, each TikTok account and the news (posts, milestones, problems).
  - **Waiting to post**: every video with its picture, held ones first. Watch it as it streams from the PC, then **OK to post**, **Post now**, **Try again** or **Delete** (asks first; cleared like Clean up does). You can edit its caption and hashtags before it posts.
  - **New video** (make a Creator video, clip links, ask for clips), **Requests** (with Cancel), **Posted** (views, likes, comments, shares), **Categories** (pause, resume, find videos now), **This week** and the **Log**.
  - **Pause** automation from the top bar. The Dock and menu bar icons count the videos waiting for your OK, and Mac notifications say when one waits, when a post goes up and when something needs you.
- **Settings → Mac app** on the PC: turn the server on, link a Mac with a code, see the linked Macs (last seen, and from where) and unlink them.

## Security
- The server is off until you turn it on, and it runs only while automation runs. Each connection is encrypted with the PC's own certificate, which the Mac pins after linking.
- Linking proves both computers saw that same certificate, so another computer on your Wi-Fi can't pose as the PC or the Mac. The code is checked through 200,000 rounds of PBKDF2 and is thrown away after five wrong tries.
- The Mac keeps its key in the macOS Keychain. The PC keeps only a hash of it. Wrong keys from one address are slowed down.
- Nothing is opened to the internet. To use it away from home, put Tailscale on both computers and type the PC's Tailscale name in the Mac app.

## Good to know
- The first time automation starts the server, Windows asks whether ClipMonster may use the network. Allow it on **private** networks.
- The Mac app isn't signed with an Apple developer ID, so macOS blocks it the first time. Open **System Settings → Privacy & Security → Open Anyway** (on macOS 14 and older, right-click → **Open**).
- The Mac app works with ClipMonster 3.6.0 or newer on the PC.

## Command line
- `ytclip auto` runs the Mac app's server too, like automation started from the app.
- `ytclip self-test` also checks the Mac app's secure connection.
