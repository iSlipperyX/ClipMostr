ClipMonster 2.5.0 clips videos much faster. It also adds a Speed setting that can put every CPU core and the graphics card to work.

## Faster
- **Whisper types out just the clips.** Transcription has a new choice, **For the clips**. YouTube's captions find the clips, then Whisper types out only the clips, plus three seconds either side, for captions and titles. That's a few minutes of speech instead of the whole video. On Oct 27, each video spent about 26 minutes in analysis, mostly Whisper typing out the whole video. Videos with no captions are still typed out whole.
  - If you had Transcription set to **Always**, it's now **For the clips**. You can set Always back in Settings → Transcription.
- **Whisper is quicker on the CPU too.** It now uses as many threads as the Speed setting allows (it used 4, whatever the PC). It also types each sentence on its own, which is faster and stops one misheard sentence from setting off a run of repeats.
- **A long video carries on where it stopped.** Typing out a whole video saves a checkpoint every 30 seconds. If automation is stopped, or the PC restarts, it picks up from there instead of starting again.
- **The next video downloads while this one is clipped.** It still waits the minutes between downloads, and a sign-in request still pauses everything. Settings → Automation → Download the next video while clipping turns it off.
- **Scene detection decodes on the graphics card** unless Speed is Quiet. That leaves the CPU free for Whisper.
- **Extra clips, then the best kept.** With AI polish, ClipMonster finds half as many clips again, the AI rates them all, and only the best rated are exported. More of your clips pass the quality check, and no time goes on encoding clips that would be rejected. It's on by default: Settings → AI → Find extra clips, keep the best the AI rates.

## New: Speed (Settings → Speed)
- **Quiet:** a quarter of the CPU threads for Whisper, and automation only uses the PC when nothing else wants it.
- **Balanced** (the default): half the threads, and automation steps aside for whatever you're doing.
- **Full power:** every CPU thread, and **Whisper on the graphics card**. It runs on AMD, NVIDIA and Intel cards through Vulkan (whisper.cpp), which suits the Radeon RX 9060 XT. The first time, it downloads a model for the card, about 550 MB for medium or large-v3-turbo. If the card can't be used, Whisper uses the CPU, and Settings → Speed and the health check say why. After a driver update, **Try the graphics card again** checks the card again.
- Whisper has a new model choice, **large-v3-turbo**. It's nearly as accurate as large-v3 and quicker than medium, especially on the graphics card.
- **`ytclip whisper-test VIDEO`** times each model on a minute of one of your videos, on the CPU and the graphics card, so you can pick the quickest one that's good enough.

## Updating
Installed copies offer this update automatically. To try the graphics card, set Settings → Speed to Full power. The Automation log's "took …" line for each video shows where the time went.
