ClipMonster 2.3.1 is a small fix for automation looking stuck.

## Fixed
- **The sign-in pause can be ended.** When YouTube asks your PC to sign in, the Automation tab now shows a **Try now** button that ends the pause and starts the videos that were waiting for it. `ytclip auto --try-now` does the same from the command line. Downloads stay spaced out further for the rest of the day.
- **Picking a browser login ends the pause by itself.** If you set **Settings → Download → Use browser login** after YouTube asked, automation tries again straight away instead of waiting out the pause.
- **A shorter first pause.** The first sign-in request now pauses for 2 hours instead of 6. A second request within a day still pauses for 6 hours.
- **A status that matches what's happening.** While paused for a sign-in, the status said "Waiting for the next check" for hours. It now says it's paused for a sign-in and until when, even while automation isn't running.
- **An empty queue says why.** When a check picks nothing, the status gives the reasons, for example "Nothing new to pick in the last check (21 videos: 11 already picked, 4 blocked words, 3 too long or short). Checks again at 00:54". Before, it only said "Waiting for the next check".
- **Ending a pause takes effect quickly.** A running automation notices Try now within a couple of seconds, instead of up to 5 minutes later.

## Tip
Videos you remove from the Automation list count as already picked, so the picking rules won't pick them again. To clip one anyway, paste its link into the Automation tab.

## Updating
Installed copies offer this update automatically. Close ClipMonster's other windows first. Automation pauses for the update and starts again afterwards.
