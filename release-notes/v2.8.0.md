ClipMonster 2.8.0 installs like a normal Windows app, updates itself more smoothly (with Beta and Dev channels for testing), uploads finished clips to Google Drive, and cleans up after itself.

## New
- **An installer.** Download **ClipMonster-Setup.exe** from the release page and run it. It installs for you only (no admin prompt) into `%LOCALAPPDATA%\Programs\ClipMonster`, out of OneDrive and the Desktop, with a Start menu entry and an Uninstall in Windows' Installed apps. Running a newer Setup.exe over it updates it in place, and stops and restarts automation for you.
  - **Already using an unzipped copy?** After this update it offers **Install now**. It downloads the installer, installs, and opens the installed ClipMonster, which then offers to remove the old copy. Your settings, niches, history and clips stay exactly where they are. Make a new shortcut if you pinned the old `ClipMonster.exe` (the installer adds one to the Start menu).
- **Updates in the background.** New versions download quietly while you work. The bar then says the update is ready: **Restart now** installs it in a few seconds, or it installs itself when you close ClipMonster. With the window closed, automation installs updates itself between videos and carries on. Turn this off with *Get updates by themselves* in Settings → Updates.
- **Update channels.** Settings → Updates → *Update channel*:
  - **Stable**: finished versions only.
  - **Beta**: also test versions of the next release.
  - **Dev**: a new build every time ClipMonster's code changes, for trying things the moment they're made. It's the least tested.
  - Switching to a steadier channel offers its newest version straight away.
- **Go back.** Settings → Updates has **Go back to** the version you had before the last update, if a new one misbehaves.
- **Updates stay out of the way.** Downloads, the unpacked update and the previous version live in `%LOCALAPPDATA%\ClipMonster\updates`, never in the program folder or OneDrive. The download is deleted as soon as it's unpacked.
- **Upload finished clips to Google Drive.** Settings → Upload. Clips upload a few minutes after they're exported, into a `ClipMonster` folder in your Drive laid out like your clips folder. Big clips go up in pieces and carry on after a dropped connection or a restart. The Automation tab shows what's uploading. Setting up takes about 10 minutes, once: follow the [Google Drive setup guide](https://github.com/iSlipperyX/ClipMostr/blob/main/docs/google-drive-setup.md). Uploading to a NAS or any folder works too.
- **Clean up: clips safely uploaded.** A new kind clears clips from the PC once the same file is in your storage and TikTok Manager doesn't need it. The uploaded copy stays.

## Changed
- **Clean up runs by itself** once a day while automation runs, for new installs and for settings from before 2.8.0. It clears unfinished downloads, previews, rejected clips, posted and removed clips, and uploaded clips. Turn it off, or pick what goes, in the Clean up window.
- **Temporary files have one home.** Exporting, Whisper, the AI polish and previews work in `%LOCALAPPDATA%\ClipMonster\work`, not Windows' temp folder. Whatever a crash leaves there is cleared at the next start, and so are the leftovers from older versions in `%TEMP%`.
- **Deleting full downloads takes their extras too.** When automation deletes a video after clipping it, the transcripts, captions and measurements saved beside it go as well.
- About shows exactly which build you have, including a dev build's commit.

## Updating
Installed copies offer this update automatically. Then use **Install now** to move to the installer.
